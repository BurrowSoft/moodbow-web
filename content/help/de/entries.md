Tippe auf **Über deinen Tag schreiben**, um einen Eintrag zu beginnen. Schreib so viel oder so wenig, wie du magst (bis zu 20.000 Zeichen), und ändere das Datum, wenn es um einen früheren Tag geht.

{pending:app_writing_prompts}Ist ein neuer Eintrag noch leer, bietet Moodbow dir vielleicht eine behutsame Frage als Anfang an; tippe auf **Andere Frage** für eine andere, oder fang einfach an zu schreiben.{/pending}

Öffne einen Eintrag, um ihn zu lesen. Um ihn zu ändern, tippe auf den Text (oder ⋯ → **Eintrag bearbeiten**); um etwas zu ergänzen, tippe unten auf **Zu diesem Eintrag hinzufügen …**.

**Entwürfe:** Während du schreibst, speichert Moodbow einen Entwurf auf deinem Gerät. Wenn du gehst, bevor du gespeichert hast, bewahrt Moodbow den Entwurf für das nächste Mal auf oder fragt, ob du ihn lieber verwerfen möchtest.

**Auf einem anderen Gerät bearbeitet?** Wenn derselbe Eintrag woanders geändert wurde, während du ihn bearbeitet hast, fragt Moodbow, welche Version du behalten möchtest: deine oder die andere. Nichts wird ohne Nachfrage überschrieben.

Um einen Eintrag zu löschen, öffne ihn und wähle ⋯ → **Löschen**. Das Löschen lässt sich nicht rückgängig machen.
