{pending:widget_live}Ajoutez le widget **Moodbow** depuis le sélecteur de widgets de votre téléphone. Appuyez sur un visage pour ouvrir Moodbow avec cette humeur déjà choisie ; rien n'est enregistré tant que vous n'appuyez pas sur **Enregistrer**. Une fois votre bilan fait, le widget affiche **C'est noté** avec le visage du jour.

Le widget n'affiche jamais ce que vous avez écrit. Si le **Verrouillage de l'app** est activé, les visages s'affichent tant que vous n'avez pas fait votre bilan ; ensuite, il affiche seulement **C'est noté**, sans visage ni mot d'humeur. En ouvrant Moodbow, votre code PIN vous est d'abord demandé.

Le widget utilise la langue choisie dans Moodbow.{/pending}
