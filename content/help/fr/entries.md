Appuyez sur **Raconter votre journée** pour commencer une note. Écrivez autant ou aussi peu que vous voulez (jusqu'à 20 000 caractères), et changez la date si elle parle d'un jour passé.

{pending:app_writing_prompts}Quand une nouvelle note est vide, Moodbow peut vous proposer une question douce pour démarrer ; appuyez sur **Une autre** pour en voir une différente, ou commencez simplement à écrire.{/pending}

Ouvrez une note pour la lire. Pour la modifier, appuyez sur le texte (ou ⋯ → **Modifier la note**) ; pour la compléter, appuyez sur **Compléter cette note…** en bas.

**Brouillons :** pendant que vous écrivez, Moodbow garde un brouillon sur votre appareil. Si vous partez avant d'enregistrer, Moodbow garde le brouillon pour la prochaine fois, ou vous demande si vous préférez l'abandonner.

**Modifiée sur un autre appareil ?** Si la même note a changé ailleurs pendant que vous l'écriviez, Moodbow vous demande quelle version garder : la vôtre ou l'autre. Rien n'est remplacé sans vous demander.

Pour supprimer une note, ouvrez-la et choisissez ⋯ → **Supprimer**. La suppression est irréversible.
