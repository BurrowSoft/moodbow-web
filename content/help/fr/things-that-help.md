title: Ce qui m'aide
summary: Une courte liste de ce qui vous aide les jours difficiles, et une minute pour respirer.
topic: Your journal
---
{pending:app_toolbox|toolbox_live}Dans **Moi → Ce qui m'aide**, gardez une courte liste de petites choses qui vous aident les jours difficiles : une promenade, une chanson, quelqu'un à qui écrire. Tapez-en une, puis appuyez sur **Ajouter**. Vous pouvez en garder jusqu'à 20, de 120 caractères maximum chacune. Utilisez **Modifier** ou **Supprimer** pour en changer une (**Rétablir** fait revenir ce que vous avez supprimé), et **Monter** ou **Descendre** pour les mettre dans l'ordre. {pending:app_toolbox}Dans l'app, ces options sont dans le menu à côté de chaque élément. {/pending}Vous seul pouvez voir cette liste.

Quand le bilan que vous avez enregistré aujourd'hui est **Très mal** ou **Pas bien**, Aujourd'hui affiche **Ce qui vous aide**, avec votre liste. **Pas maintenant** la masque pour le reste de la journée sur cet appareil. Si vous changez le bilan du jour pour une meilleure humeur, elle disparaît.

**Respirer une minute** ouvre **Une minute pour respirer** : inspirez sur 4, expirez sur 6, pendant une minute, puis cela s'arrête tout seul. **Arrêter** est toujours là. Si vous avez la tête qui tourne, arrêtez et respirez normalement. Vous pouvez aussi le lancer depuis **Moi → Ce qui m'aide**.{/pending}
