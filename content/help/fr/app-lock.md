{pending:app_app_lock}Dans l'app, ouvrez **Moi → Verrouillage de l'app** pour choisir un code PIN de 4 à 6 chiffres, et activez le déverrouillage par empreinte ou par visage si votre téléphone le permet. Vous pouvez aussi choisir quand l'app se verrouille : immédiatement, après 1 minute ou après 5 minutes.

Votre code PIN reste sur votre téléphone et ne nous est jamais envoyé. Quand l'app est verrouillée, son aperçu dans le sélecteur d'apps de votre téléphone est masqué{pending:widget_live}, et sur Android le widget de l'écran d'accueil n'affiche rien de personnel{/pending}.

**Code PIN oublié ?** Appuyez sur **Code PIN oublié ?** pour vous déconnecter. Quand vous vous reconnectez, le verrouillage est supprimé et vous pouvez en choisir un nouveau. Le verrouillage existe seulement dans l'app, pas sur le web.{/pending}
