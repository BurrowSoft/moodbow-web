{pending:shortcuts_live}Sur le web, appuyez sur **?** pour voir les raccourcis : **n** écrit une nouvelle note, **c** ouvre le bilan du jour, **t** mène à Chronologie, **i** à Statistiques, et **/** ouvre la recherche dans Chronologie. Ils ne fonctionnent pas pendant que vous tapez dans un champ, pour ne jamais vous gêner.

Ils suivent les lettres que tape votre clavier : avec une disposition non latine (le thaï, par exemple), passez à une disposition latine pour les utiliser. Si vous utilisez la commande vocale ou s'ils vous gênent, désactivez-les dans **Moi → Apparence → Raccourcis clavier**.{/pending}
